# Выборы на политфаке — Quarto + R

Откройте `index.qmd` в Positron и нажмите Render.
Перед первой сборкой положите ID Google-таблицы в файл `sheet_id.txt` в корне проекта
(или задайте переменную окружения `POLITFAK_SHEET_ID`). Файл исключён из Git:
по ID открываются сырые ответы, поэтому в публичном репозитории его нет.
Каждая сборка напрямую загружает первую вкладку Google Sheets, очищает данные
и создаёт HTML в `output/`. Ошибка сети останавливает сборку, старый снимок не используется.
Для интерактивной работы в консоли: `source("R/prepare_data.R")`.

Зависимости R: dplyr, tidyr, readr, haven, knitr, rmarkdown. Нужен установленный Quarto CLI.
Для графиков: ggplot2, forcats, scales, patchwork, ragg.
Для интерактивности: ggiraph. Все графики в HTML — SVG-виджеты с подсказками.
MCA убран из актуального отчёта; его экспериментальный код сохранён отдельно.
Для старого MCA: FactoMineR и ggrepel. Партия, пол и категории TIPI — дополнительные;
активны курс, внимание, принадлежность, важность исхода, отношение к ИИ.
Координаты, качество проекции, инерция и профили сохраняются в data/processed/.
Группы без ответивших с правом голоса исключаются из разбивок.
График переходов 2025/26 → сейчас также включает только имеющих право голоса.
Дополнительные разделы: первый/второй выбор, матрица вторых предпочтений,
распределения важности факторов и средние TIPI с 95% t-интервалами.
Они рассчитаны среди имеющих право голоса; совпавшая партия второго выбора
не учитывается повторно. Все новые диаграммы также сохраняются в figures/.
Четыре графика и две композиции patchwork автоматически сохраняются в `figures/` (PNG, 300 dpi).
Доли и 95% интервалы Уилсона рассчитаны только среди имеющих право голоса
внутри каждой группы, включая неопределившихся. Сортировка партий — по числу
ответов имеющих право голоса. Серые столбики справа — отдельное число ответов
без права голоса. Интервалы не учитывают самоотбор.
Таблица сейчас доступна на чтение без OAuth. Если доступ закроется, загрузку надо
перевести на googlesheets4 с авторизацией; не публикуйте ответы ради работы скрипта.

`data/` и `output/` исключены из Git: там исходные ответы и локальный отчёт.
Изменения названий вопросов, неоднозначное сопоставление и пропавшие столбцы
вызывают понятную ошибку. Правила сопоставления находятся в `R/prepare_data.R`.
Фильтрация тестовых ответов не выполняется.
Классические тесты находятся в R/statistical_tests.R: Спирмен, Фишер и Краскел—Уоллис.
Поправка на множественные сравнения не применяется; результаты и численности
сохраняются в data/processed/. Анализ разведочный, самоотбор тестами не устраняется.

Новые разделы (R/new_sections.R и R/mca_portraits.R):
подписка на каналы против голоса, свободные ответы «что ещё влияет»,
критика соперников и интерес к выборам, карта MCA с портретами сторонников,
поток ответов во времени и флаги небрежных анкет.
Небрежная анкета — один балл во всех пунктах TIPI или согласие с противоположными
утверждениями пары; из основных разделов она не удаляется, из карты MCA — исключается.
В новой карте MCA партия активна (отличие от старого R/mca.R); устойчивость проверяется
той же картой, где партия — дополнительная переменная. Доля инерции — с поправкой Гринакра.
Свободные ответы с упоминанием конкретных людей не публикуются.
Итоговая модель (R/party_model.R, пакет nnet): мультиномиальная логистическая регрессия
первого выбора среди партий с n ≥ 10 по полу, курсу, общительности, эмоциональной устойчивости,
важности подачи и программы; все попарные сравнения партий, forest plot отношений шансов,
LR-тесты вклада признаков и точность при отложенной проверке (leave-one-out).

Публикация: `output/index.html` выкладывается в ветку `gh-pages` (GitHub Pages).

Хи-квадраты (R/chi_tests.R) проверяют описательные выводы: выбор × пол, курс, прошлый голос,
второй выбор, критика и интерес, подписка на канал × голос. При ожидаемых частотах меньше 5
p считается методом Монте-Карло. Текст отчёта написан простым языком; числа и выводы
в нём считаются из данных (R/text_helpers.R), таблицы проверок свёрнуты в «Подробности».
